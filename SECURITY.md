# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in any DatologyAI repository, product or service, please report it privately by email to **security@datologyai.com**.

Please include:

- a description of the issue and its potential impact,
- steps to reproduce, or a proof of concept,
- the affected repository, URL or component, and any relevant versions.

Please **do not** open a public GitHub issue, pull request or discussion for security problems.

## What to expect

- We will acknowledge your report within 5 business days.
- We will investigate, keep you informed of our progress where we can, and let you know when the issue is resolved.
- Please give us a reasonable amount of time to fix the issue before any public disclosure.

## Scope

This policy covers repositories in the [datologyai](https://github.com/datologyai) GitHub organization and DatologyAI-operated services. Reports about third-party software should go to the respective vendor.

DatologyAI does not currently run a paid bug bounty program.
